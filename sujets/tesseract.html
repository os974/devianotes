Tesseract

Le moteur OCR open-source de référence, maintenu par Google. Extrait du texte depuis n'importe quelle image (photo, scan, PDF rasterisé) en plus de 100 langues, gratuitement, sans connexion. Le point de départ obligé de tout projet de reconnaissance de texte.

À quoi ça sert

L'OCR (Optical Character Recognition) transforme une image contenant du texte en texte exploitable par une machine. Cas d'usage typiques :

  • Numériser des documents papier — factures, contrats, courriers scannés.
  • Extraire les champs d'une pièce d'identité (KYC, vérification client, onboarding).
  • Lire des panneaux ou plaques d'immatriculation depuis des caméras.
  • Indexer le contenu textuel de PDFs scannés pour les rendre recherchables.
  • Pré-traitement avant un LLM — sortir le texte brut d'un document, puis demander à un LLM de le structurer.

Tesseract est l'outil de référence parce qu'il est :

  • Gratuit et open-source (Apache 2.0).
  • Local — pas d'envoi de tes documents à un service tiers, ce qui compte pour des données sensibles (santé, juridique, RGPD strict).
  • Multi-langues — 100+ langues officielles, dont français, arabe, chinois, alphabets non-latins.
  • Mature — première version en 1985, encore amélioré aujourd'hui (v5 utilise un réseau LSTM moderne).
Tesseract, EasyOCR, PaddleOCR, LLM vision… c'est quoi la différence ?

Tesseract = moteur classique, basé règles + LSTM. Très bon sur du texte propre, dégrade vite si l'image est bruitée. EasyOCR et PaddleOCR sont des moteurs deep learning modernes : meilleurs sur les images difficiles (photos floues, textes manuscrits), mais plus lents et plus gourmands en GPU. LLM vision (GPT-4 Vision, Claude vision, LLaVA) « lit » l'image directement et peut même la structurer en JSON — état de l'art en 2026, mais payant et non-local. En pratique : commencer par Tesseract pour un prototype, monter en gamme si la qualité de l'image l'exige. Cf. retex POC KYC pour une comparaison concrète.

Un exemple d'usage

Extraire le texte d'une facture scannée en quelques lignes :

python 
import pytesseract
from PIL import Image

img = Image.open("facture.jpg")

# Texte brut, langue française
texte = pytesseract.image_to_string(img, lang="fra")
print(texte)

# Avec position de chaque mot (utile pour rechercher des champs)
data = pytesseract.image_to_data(img, lang="fra",
                                   output_type=pytesseract.Output.DICT)
for i, mot in enumerate(data["text"]):
    if mot.strip():
        print(f"{mot}",
              data["left"][i], data["top"][i],
              data["width"][i], data["height"][i])

image_to_string renvoie le texte concaténé. image_to_data renvoie en plus la position (bounding box) de chaque mot, ce qui permet par exemple de repérer le champ « Total TTC » ou un numéro de pièce dans la page.

How-to : installer et utiliser Tesseract

  1. Installer Tesseract sur le système

    Tesseract est un binaire système, pas un paquet Python. Sur Debian/Ubuntu :

    bash 
    sudo apt install tesseract-ocr

# Paquets de langue (à ajouter selon tes besoins)
sudo apt install tesseract-ocr-fra tesseract-ocr-eng

# Vérifier
tesseract --version
tesseract --list-langs

    Sur macOS : brew install tesseract tesseract-lang. Sur Windows : installeur sur le site officiel.

    Dans un Dockerfile

    Pour livrer ton app : RUN apt-get update && apt-get install -y tesseract-ocr tesseract-ocr-fra dans un Dockerfile basé sur python:slim. Ça évite que les utilisateurs de ton image n'aient à installer Tesseract à la main.

  2. Installer le binding Python

    pytesseract appelle simplement le binaire Tesseract derrière. Avec UV :

    bash 
    uv add pytesseract pillow

    Pillow est requis pour ouvrir les images. OpenCV peut aussi servir pour du pré-traitement plus poussé.

  3. Extraction de base

    python 
    import pytesseract
from PIL import Image

img = Image.open("document.png")

# Anglais (par défaut)
texte = pytesseract.image_to_string(img)

# Une autre langue, ou plusieurs en même temps
texte_fr = pytesseract.image_to_string(img, lang="fra")
texte_multi = pytesseract.image_to_string(img, lang="fra+eng")

  4. Pré-traitement de l'image (clé du succès)

    Tesseract donne ses meilleurs résultats sur une image en noir sur blanc, sans bruit, droite. Quelques étapes de pré-traitement font souvent la différence entre 60% et 95% de précision :

    python 
    import cv2
import numpy as np
from PIL import Image
import pytesseract

# 1. Lire en niveaux de gris
img = cv2.imread("scan.jpg", cv2.IMREAD_GRAYSCALE)

# 2. Binariser (seuillage adaptatif, robuste aux variations de lumière)
img = cv2.adaptiveThreshold(
    img, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY, 31, 15,
)

# 3. Léger débruitage
img = cv2.medianBlur(img, 3)

# 4. Passer à Tesseract via une Image PIL
texte = pytesseract.image_to_string(Image.fromarray(img), lang="fra")

    Sur des photos prises au smartphone, ajouter déskew (redressement) et resize à 300 DPI minimum si l'image est petite.

  5. Modes de segmentation de page (PSM)

    Tesseract a besoin d'un indice sur la structure de la page. Le mode par défaut suppose une page entière de texte. Pour autre chose (un seul mot, un bloc isolé, une ligne), il faut le préciser :

    python 
    # PSM 6 = bloc de texte uniforme (souvent meilleur que le défaut)
texte = pytesseract.image_to_string(img, config="--psm 6")

# PSM 7 = une seule ligne de texte (utile pour plaques d'immatriculation)
texte = pytesseract.image_to_string(img, config="--psm 7")

# PSM 8 = un seul mot
texte = pytesseract.image_to_string(img, config="--psm 8")

# PSM 11 = texte sparse, sans ordre particulier (étiquettes, captures…)
texte = pytesseract.image_to_string(img, config="--psm 11")

    Liste complète : tesseract --help-psm. Tester plusieurs PSM est souvent la première chose à faire si la sortie est mauvaise.

  6. Restreindre les caractères acceptés (whitelist)

    Quand tu sais que tu attends seulement des chiffres ou un alphabet précis, le dire à Tesseract réduit drastiquement les erreurs :

    python 
    # Une plaque d'immatriculation belge : lettres maj + chiffres
config = "--psm 7 -c tessedit_char_whitelist=ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789-"
plaque = pytesseract.image_to_string(img_plaque, config=config)

  7. Récupérer la position des mots (bounding boxes)

    Indispensable dès qu'on doit retrouver un champ précis dans un document :

    python 
    data = pytesseract.image_to_data(
    img, lang="fra",
    output_type=pytesseract.Output.DATAFRAME,   # pandas !
)

# DataFrame avec colonnes : text, conf, left, top, width, height…
mots_fiables = data[data["conf"] > 60]
print(mots_fiables[["text", "conf", "left", "top"]])

    conf est la confiance de Tesseract (0–100). Filtrer sur conf > 60 élimine les pseudo-mots extraits du bruit de l'image.

  8. OCR + LLM : duo gagnant pour structurer

    Tesseract sort du texte brut, pas du JSON structuré. Le pattern moderne : Tesseract pour l'extraction → un LLM (via Ollama ou Hugging Face) pour la mise en forme.

    python 
    import pytesseract, httpx, json
from PIL import Image

texte = pytesseract.image_to_string(Image.open("facture.jpg"), lang="fra")

# Demander à un LLM local de structurer
prompt = f"""Voici le texte d'une facture. Extrais en JSON :
{texte}

Réponds UNIQUEMENT avec un objet JSON avec ces champs :
numero, date, total_ttc, fournisseur."""

r = httpx.post("http://localhost:11434/api/chat", json={
    "model": "llama3.2",
    "messages": [{"role": "user", "content": prompt}],
    "format": "json",
    "stream": False,
}, timeout=120)

facture = json.loads(r.json()["message"]["content"])
print(facture)

    C'est exactement le pattern décrit dans le retex POC KYC : OCR pour extraire, LLM pour structurer. Tesseract donne le texte, le LLM lui donne du sens.

import pytesseract
from PIL import Image
img = Image.open("…")
pytesseract.image_to_string(img, lang="fra")
pytesseract.image_to_data(img, output_type=pytesseract.Output.DATAFRAME)
pytesseract.image_to_boxes(img)             # caractères
python (config) 
config = "--psm 6 --oem 1"
config += " -c tessedit_char_whitelist=0123456789"
pytesseract.image_to_string(img, config=config)
python (preprocessing typique) 
import cv2
g = cv2.imread("…", cv2.IMREAD_GRAYSCALE)
g = cv2.adaptiveThreshold(g, 255,
        cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 31, 15)
g = cv2.medianBlur(g, 3)

Tesseract et le reste de l'écosystème

  • Pillow — ouvre les images dans le format attendu par pytesseract. Pour des manipulations simples (resize, rotate, convert), Pillow suffit.
  • OpenCV — pré-traitement sérieux : binarisation adaptative, débruitage, déskew, normalisation de contraste. Quasiment indispensable sur des photos non-scannées.
  • Ollama / Hugging Face — le combo « OCR + LLM » : Tesseract extrait le texte brut, un LLM le structure en JSON ou répond à des questions sur son contenu. Pattern documenté dans le retex POC KYC.
  • FastAPI — pour exposer Tesseract comme service web : un endpoint POST /ocr qui reçoit une image en upload, la passe à Tesseract, renvoie le texte.
  • pandas — image_to_data sait sortir un DataFrame directement. Filtrer par conf, regrouper par ligne, c'est du pandas standard.
  • Docker — installer Tesseract dans le Dockerfile de ton app évite la galère « tesseract not found » au déploiement.
Quand passer à un autre OCR ?

Si Tesseract donne moins de 80% de précision après pré-traitement sérieux, c'est probablement l'image qui est le problème. Tente EasyOCR ou PaddleOCR (deep learning, plus robustes au bruit) avant d'envisager un LLM vision. Si le but est d'extraire des champs structurés d'un document complexe (formulaires, tableaux), regarde du côté des LLM vision (GPT-4V, Claude vision) — ils font OCR + structuration en un seul appel.
