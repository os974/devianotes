seaborn

Une surcouche statistique à matplotlib qui produit des graphiques jolis par défaut en une seule ligne. Idéal pour l'exploration de données dans Jupyter : distributions, corrélations, régressions, heatmaps — tout ce qui demanderait dix lignes en matplotlib en demande une en seaborn.

À quoi ça sert

seaborn sert à tracer rapidement des graphiques statistiques propres à partir d'un DataFrame pandas. L'idée centrale : on passe le DataFrame entier et on précise quelles colonnes vont en X, en Y, en couleur — seaborn fait le reste (légende, axes, palette, agrégations).

Quelques cas typiques :

  • Distribution — histplot, kdeplot, boxplot, violinplot pour visualiser la forme d'une variable.
  • Relation entre deux variables — scatterplot, lineplot, regplot (avec droite de régression).
  • Comparaison entre groupes — barplot, boxplot avec un argument hue pour séparer par catégorie.
  • Matrice de corrélation — heatmap sur le df.corr() de pandas, le réflexe d'exploration n°1.
  • Vue d'ensemble multi-variables — pairplot qui croise toutes les colonnes deux à deux.
seaborn ou matplotlib ?

seaborn est construit au-dessus de matplotlib : tout graphique seaborn est un graphique matplotlib qu'on peut customiser après coup avec l'API ax habituelle. Règle simple : seaborn pour avoir vite quelque chose de propre (exploration, rapports), matplotlib pur dès qu'on veut contrôler chaque détail (publication, intégration dans une appli). En pratique, on passe souvent par les deux dans le même notebook.

Un exemple d'usage

Reprenons le DataFrame de ventes : on veut visualiser la distribution du montant par produit, avec un boxplot, en une ligne.

python 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("ventes.csv")

# Un boxplot par produit, coloré par région
sns.boxplot(data=df, x="produit", y="montant", hue="region")
plt.title("Distribution des ventes par produit et région")
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig("ventes_box.png", dpi=150)
plt.show()

Le pattern à retenir : sns.<type_de_plot>(data=df, x=..., y=..., hue=...). L'argument hue ajoute une dimension par couleur, l'argument col (sur les variantes *plot de haut niveau) crée une grille de sous-graphes. La sauvegarde et l'affichage restent gérés par matplotlib (plt.savefig, plt.show).

How-to : installer et utiliser seaborn

  1. Installer seaborn

    Dépendance simple (cf. UV). seaborn installe automatiquement matplotlib et pandas :

    bash 
    uv add seaborn

    Convention d'import : import seaborn as sns. On importe presque toujours matplotlib en même temps pour ajuster titres, tailles ou sauvegarder.

  2. Partir d'un DataFrame « long »

    seaborn raisonne en données « tidy » (format long) : une ligne = une observation, une colonne par variable. Si tes données sont en format large (un produit par colonne), convertis-les d'abord :

    python 
    # Large → long avec pandas
df_long = df.melt(
    id_vars="date",
    value_vars=["produit_A", "produit_B"],
    var_name="produit",
    value_name="ventes",
)

sns.lineplot(data=df_long, x="date", y="ventes", hue="produit")

  3. Les graphiques les plus utiles en exploration

    python 
    # Distribution d'une variable
sns.histplot(data=df, x="montant", kde=True)
sns.kdeplot(data=df, x="montant", hue="region")

# Comparaison par groupe
sns.boxplot(data=df, x="produit", y="montant")
sns.violinplot(data=df, x="produit", y="montant")
sns.barplot(data=df, x="produit", y="montant")  # moyenne + IC

# Relation entre deux variables
sns.scatterplot(data=df, x="poids", y="prix", hue="categorie")
sns.regplot(data=df, x="poids", y="prix")        # + droite de régression
sns.lineplot(data=df, x="date", y="ventes")

  4. Matrice de corrélation en heatmap

    Le réflexe pour repérer rapidement les liens entre variables numériques avant d'attaquer un modèle scikit-learn :

    python 
    corr = df.select_dtypes("number").corr()

sns.heatmap(corr,
            annot=True,             # afficher les valeurs
            fmt=".2f",
            cmap="coolwarm",
            center=0,
            vmin=-1, vmax=1)
plt.title("Matrice de corrélation")

  5. Pairplot pour une vue d'ensemble

    En une commande, on obtient toutes les paires (scatter) et toutes les distributions (histogramme sur la diagonale). Très utile en début d'EDA :

    python 
    sns.pairplot(df, hue="espece", diag_kind="kde")
    Attention au coût

    pairplot trace N×N graphes. Avec un DataFrame qui a 20 colonnes numériques, c'est 400 sous-graphiques — lent et illisible. Filtre avec l'argument vars=[...] ou applique pairplot sur un échantillon.

  6. Customiser après coup avec matplotlib

    Toute fonction seaborn retourne un objet matplotlib (Axes ou FacetGrid). On peut donc chaîner avec l'API matplotlib habituelle pour ajuster :

    python 
    ax = sns.boxplot(data=df, x="produit", y="montant")
ax.set_title("Ventes par produit")
ax.set_ylabel("Montant (€)")
ax.tick_params(axis="x", rotation=45)
plt.tight_layout()
plt.savefig("out.png", dpi=150)

  7. Thèmes et palettes

    Une ligne change l'allure de tous les graphiques du notebook :

    python 
    # Style global (whitegrid, darkgrid, white, dark, ticks)
sns.set_theme(style="whitegrid", context="notebook")

# Palette pour les couleurs catégorielles
sns.set_palette("Set2")        # pastel, deep, muted, colorblind...

# Palette ponctuelle sur un seul plot
sns.barplot(data=df, x="produit", y="montant", palette="viridis")
    Le réflexe accessibilité

    La palette "colorblind" est lisible par la majorité des daltoniens. Pour des données continues, préfère "viridis" ou "magma" aux arcs-en-ciel (jet) qui déforment la perception des écarts.

  8. Grilles de sous-graphes avec FacetGrid / catplot

    Les fonctions de haut niveau (relplot, displot, catplot) acceptent col et row pour découper les données :

    python 
    # Un scatter par région, deux colonnes
sns.relplot(data=df,
            x="poids", y="prix",
            hue="categorie",
            col="region", col_wrap=2,
            height=4)

seaborn et le reste de l'écosystème

  • matplotlib — la couche qui dessine vraiment. Tout objet seaborn est manipulable avec l'API matplotlib (ax.set_title, plt.savefig…). Connaître matplotlib reste indispensable pour personnaliser.
  • pandas — la source de données quasi-universelle pour seaborn. L'argument data=df accepte directement un DataFrame, et beaucoup de plots font des agrégations en interne (moyenne, IC) avec groupby.
  • Jupyter — l'environnement naturel pour itérer sur un graphique. Les figures seaborn s'affichent sous la cellule comme n'importe quel fig matplotlib.
  • scikit-learn — la heatmap de corrélation et le pairplot sont les deux outils standards pour explorer un dataset avant un modèle. sns.heatmap sur une matrice de confusion confusion_matrix(...) est aussi le réflexe d'évaluation.
  • Streamlit — affiche une figure seaborn via st.pyplot(fig) (puisque c'est une figure matplotlib en dessous). Pratique pour livrer un mini-EDA à un métier.
Quand seaborn ne suffit plus

seaborn brille pour l'exploration et les visualisations statistiques standards. Dès qu'on a besoin de graphiques très spécifiques (annotations complexes, axes secondaires, animations) ou interactifs (zoom, survol), on passe à matplotlib pur ou à plotly. Et pour un dashboard métier en production, on n'utilise pas seaborn — on rend du HTML avec Streamlit ou un outil dédié.
